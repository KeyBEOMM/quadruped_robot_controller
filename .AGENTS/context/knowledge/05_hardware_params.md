## 5.2. 조립 기준 (mount_offset) — Phase 5 확정

> 모든 서보를 1500us (90°) 상태에서 아래 물리 자세로 혼 체결.

| 관절 | mount_offset | 서보 90° 조립 자세 | 특이점 위치 |
|---|---|---|---|
| HAA | `π/2` (90°) | 다리 수직 중립 | 없음 |
| HFE | `2π/3` (120°) | 허벅지 30° 후방 기울기 | — |
| KFE | `π` (180°) | 허벅지-종아리 직각(90°) | 완전 신장 → 서보 180°→175° 클램핑 |

> **knee_dir = +1.0f** (`<` 형태, 후방 무릎) — `LocomotionController.h` 확정

## 5.4. PCA9685 / 서보 드라이버

| 파라미터 | 확정값 | 확정 근거 |
|---|---|---|
| `PCA9685_OSC_FREQ` | **27,700,000 Hz** | Phase 5 보드 클럭 튜닝 — 27.7MHz에서 500~2500us span 최대 부합 |
| PWM 변환식 | `usec = 500 + (angle_deg / 180.0) × 2000` | Phase 5 확정 |
| 각도 클램핑 범위 | **5° ~ 175°** | 물리 한계 0°/180° 대비 안전 마진 ±5° |
| Rate Limit | **4.65 rad/s** | 모터 기계 속도 ~5.82 rad/s × 80% 안전 마진 |
| Deadband | **0.5°** | 하드웨어 미반응 구간 0.45° 기반 소프트웨어 밴드 |
| I2C 주소 | 0x40 (PCA9685 기본값) | - |

## 5.3. 제어 루프 실측 성능

| 항목 | 실측값 | 검증 Phase |
|---|---|---|
| `dt_ms` | **20.00 ms** | Phase 3 — 50Hz 칼주기 ✓ |
| `pipeline_us` (보행 파이프라인 연산) | **50~90 μs** | Phase 3 — 20,000μs 예산 대비 0.25~0.45% |
| `mutex_us` | **4 μs** | Phase 3 |
| 최대 pipeline_us (측정) | **< 10,000 μs** | Phase 4 — 100Hz (10ms) 전환 가능성 확인 ✓ |

> **100Hz 전환 결정:** Phase 4에서 10ms 이내 확인 완료 → **Phase 8에서 100Hz(`pdMS_TO_TICKS(10)`)로 전환 예정**
