# 1. System Architecture (RTOS Task Allocation)

본 문서는 ESP32 환경에서 쿼드루페드(Quadruped) 로봇 하위 제어기(`controller`)의 듀얼 코어 아키텍처 및 메모리 무결성 원칙을 정의합니다. 
이 룰셋은 RTOS 환경의 메모리 경합과 연산 지연(Jitter)을 방어하기 위한 가장 핵심적인 체계입니다.

## 1.1. Core Separation Policy (듀얼 코어 역할 분리)

ESP32의 듀얼 코어는 철저히 **비동기적(Asynchronous)**으로 동작하여, 통신 IO에 의한 지연이 실시간 제어를 방해하지 않도록 역할을 분리합니다.

### Core 0 (`CommTask` - 비동기 통신 및 상태 수집)
*   **주요 역할:** 상위 제어기(ROS 2 PC 또는 조종기)로부터 목표 속도(`vx`, `vy`, `wz`) 및 자세 명령을 수신하여 내부 데이터 포맷으로 파싱합니다.
*   **데이터 무결성 룰:**
    1.  **Timestamp 갱신:** 수신된 외부 명령 패킷에는 `esp_timer_get_time()` 등으로 '수신 타임스탬프'를 반드시 덧붙여야 합니다.
    2.  **안전한 쓰기 (Write):** 파싱된 커맨드를 공유 메모리(`SharedData`) 영역에 쓸 때는 반드시 **상호 배제(Mutex) 락**을 사용하여, Core 1이 읽는 도중 데이터가 오염되는 현상(Data Tearing)을 원천 차단해야 합니다.

### Core 1 (`ControlTask` - 실시간 제어 및 타이밍 관리)
*   **주요 역할:** 엄격한 정주기(예: 50Hz / 20ms)로 깨어나 로봇의 상태 전이, 3D 보행 패턴, 역운동학을 계산하고 최종 액추에이터 제어 신호를 출력합니다.
*   **안전 접근 룰:**
    1.  **Lock 최소화 원칙 (Snapshot):** 매 루프 시작 직후, Mutex를 획득하여 최신 커맨드의 '스냅샷'만 로컬 메모리로 깊은 복사(`memcpy` 또는 대입)하고 즉시 락을 해제합니다. 기구학 연산 중에 락을 쥐고 있어서는 절대 안 됩니다.

## 1.2. Critical Safety Enforcements (필수 안전 기제)

로봇 하드웨어의 파손 방지 및 시스템 데드락을 방어하기 위한 절차입니다. 설계 및 구현 시 반드시 준수해야 합니다.

### Rule A: 제한된 Mutex 영역 (No Blocking in Mutex)
*   **배경:** Lock을 쥐고 있는 상태에서 로그 출력(`Serial.print`)이나 무거운 기구학 연산을 수행하면 Core 0과 Core 1 사이에 데드락(Deadlock)이나 인터럽트 지연이 발생합니다.
*   **원칙:** Mutex 영역은 오직 **단순 변수(스냅샷)의 복사**에만 사용하고 한 줄이라도 더 머물지 않고 즉시 해제합니다. I/O 작업, 할당, 복잡한 연산은 Lock 밖에서 수행합니다.

### Rule B: 이중 Watchdog 방어 체계 (Dual Watchdog)
통신 불가 및 코어 프리징(Freezing) 상황 모두에 대응합니다.

1.  **Software Watchdog (상태 이상 감지):**
    *   **로직:** Core 1 제어 루프 진입 시, 커맨드 스냅샷의 타임스탬프와 현재 시스템 시간 간의 차이를 검사합니다.
    *   **조치:** 임계 시간(예: 100ms) 초과 시 상위 통신 단절로 간주하고, 즉시 글로벌 로봇 상태를 `ERROR`로 강제 전환하여 안전하게 주저앉기(Locking)를 수행합니다.
2.  **Hardware Watchdog (TWDT - Task Watchdog Timer):**
    *   **배경:** 만약 Core 1 기구학 루프 자체가 무한 루프나 데드락에 빠지면 Software Watchdog마저 검사할 수 없습니다.
    *   **로직:** `esp_task_wdt_add()` 등으로 Core 1 태스크 자체를 타임아웃 감시 대상에 등록하고, 매 50Hz 루프 안보이는 곳에서 명시적으로 `esp_task_wdt_reset()`을 호출하여 물리적인 코어 멈춤을 감시합니다. 시스템 프리징 시 하드웨어를 강제 리셋합니다.
