# 2. System State Machine (글로벌 상태 전이 로직)

로봇 컨트롤러의 생애주기(Lifecyle)를 관리히는 중심 로직입니다. 
`ControlTask`(Core 1)는 매 프레임 이 **글로벌 상태**(`RobotState`)에 따라 기구학 파이프라인의 분기(Branching)를 완벽히 분리하여 실행합니다.

---

## 2.1. Global States Definition

로봇 단일 진실 공급원이 되는 5가지 핵심 상태입니다. 어떠한 경우에도 로봇은 이 5가지 상태 중 하나에만 존재해야 합니다.

1.  **`INIT` (초기화 및 기립 보간)**
    *   **진입 조건:** 전원 인가 직후 (부팅 상태) 또는 `ERROR` 상태에서 수동 리셋 명령 수신 시.
    *   **동작 방식 (Soft-Start Blind Interpolation):** 전원 인가 시 기동 충격(Boot Snap) 방어를 위해 도입되었습니다. 하드웨어가 바닥에 완전히 엎드려 있다고 가정하는 초기 각도에서부터 기본 대기 자세인 `IDLE` 각도까지, 3~5초에 걸쳐 천천히 PWM을 보간(Interpolation)하며 로봇을 일으켜 세웁니다.
    *   **이탈 조건:** 기립 보간이 100% 완료되면 자동으로 `IDLE`로 전이.

2.  **`IDLE` (대기 상태)**
    *   **진입 조건:** `INIT` 완료 후 또는 `TRANSITION` 완료 후.
    *   **동작 방식:** 4개의 다리가 지면에 닿아있는(STANCE) 기본 정지 자세입니다. 이때 4개 발의 착지점 좌표는 각 어깨 오프셋 직하방 좌표인 **Home Stance Position**(`Z=0`)으로 완전히 초기화되며, 모터 각도를 유지(Hold)합니다. 
    *   **이탈 조건:** 수신된 커맨드 속도(`vx, vy, wz`) 중 유효한 추진력이 감지(예: 절댓값이 특정 데드밴드 임계 초과)될 경우 `TROT`으로 전이. 이때 유지하고 있던 Home Stance Position이 트롯 보행 궤적의 첫 번째 `start_pos`로 사용됩니다.

3.  **`TROT` (보행 파이프라인 활성)**
    *   **진입 조건:** `IDLE`에서 유효 이동 명령 수신 시.
    *   **동작 방식:** Edge Detection 기법과 기구학 파이프라인(Trajectory Generation $\rightarrow$ Body Kinematics $\rightarrow$ Inverse Kinematics)이 완전 활성화되어, 동적 보행을 수행합니다.
    *   **이탈 조건:** 목표 명령 속도가 완전히 `0`이 되거나 명시적인 정지 명령이 수신되면 `TRANSITION`으로 전이.

4.  **`TRANSITION` (정지 보간)**
    *   **진입 조건:** 보행 중 정지 명령(`TROT` 이탈) 발생 시 즉시.
    *   **동작 방식:** 공중에 떠 있는 스윙(SWING) 다리를 현재 위치에서 가장 가까운 기본 착지점(Home Stance)으로 부드럽게 복귀시킵니다. 트롯 보행 중 불완전한 상태로 다리가 멈추는 것을 방지합니다.
    *   **이탈 조건:** 진행 중이던 스텝의 착지 보간이 끝난 직후 `IDLE`로 자동 전이.

5.  **`ERROR` (안전 및 치명적 오류 잠금)**
    *   **진입 조건:** Watchdog 타임아웃(통신 두절 감지 시 즉각 개입) 발생 시.
    *   **동작 방식:** 로봇의 물리적 상해를 막는 최후의 보루입니다. 진행 중이던 모든 보행 연산을 강제 중단하고, 미리 지정된 최고 안전 자세(주저앉기 자세 등)로 급속 진입합니다. 그 후 모든 상태 전이를 거부(Locking)합니다.
    *   **이탈 조건:** 네트워크 통신이 재개되더라도 절대 자동으로 복귀하지 않습니다. 사용자의 상위 제어기(명시적 패킷)를 통해 'Reset Command'가 인입될 때만 `INIT` 상태로 복귀하여 다시 재기립 절차를 수행합니다.

## 2.2. State Transition Event Flow

간략화된 글로벌 상태 전이 흐름은 다음과 같습니다:

```text
[ Power ON ] 
   │
   ▼
[ INIT ] (Boot 보간) ──(완료)──┐
   ▲                         ▼
   │(Reset Cmd)           [ IDLE ] (Home Stance 유지)
   │                         │    ▲
   │                         │    │ (정지 완료)
   │                       (이동) │
   │                         ▼    │
   │                      [ TROT ] (동적 보행)
   │                         │
[ ERROR ] (잠금) ◀─┐         │ (정지 명령)
   ▲               │         ▼
   │(Timeout)      └─ [ TRANSITION ] (공중 발 회수)
   │
[ANY STATE] (Watchdog 감시 루프 개입)
```
